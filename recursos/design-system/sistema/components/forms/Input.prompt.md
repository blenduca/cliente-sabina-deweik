Single-line text field with label, hint and error state.

```jsx
<Input label="Seu e-mail" placeholder="voce@empresa.com" type="email" />
<Input label="Nome" error="Campo obrigatório" />
```

Focus shows the amarelo glow ring (`--focus-ring`) and accent border. `size` md (default) is a 44px touch target. Reskins automatically under the light theme.
