# Button

\`\`\`jsx
<Button variant="dark" icon>Quero entrar na comunidade</Button>
<Button variant="light" icon>Solicitar proposta</Button>
\`\`\`

Variants:
- `dark` — solid black pill, amarelo text. The primary CTA (hero, final CTA).
- `light` — solid amarelo pill, black text. Secondary CTA on dark sections.

`icon` appends the trailing → arrow. `size` lg is the oversized hero/closing CTA. Both are full pills (`--radius-pill`).
